2. ROOT CAUSE (why no token helps, and why 1.2.13 is the answer)
----------------------------------------------------------------
The three-package OMV split the code needs — OpenMetaverse, OpenMetaverse.Types,
OpenMetaverse.StructuredData — is NOT fully on public nuget.org:
  - public nuget.org: OpenMetaverse + OpenMetaverse.StructuredData only at 0.9.3.3318,
    and OpenMetaverse.Types does NOT exist there at all (BlobNotFound).
  - the 1.x split with a separate OpenMetaverse.Types exists ONLY on:
       * NGC private feed  -> 1.0.6  (unreachable for John)
       * John's machine    -> 1.2.13 (see §3)
NGC's 1.0.6 and public/local 1.2.13 are the SAME lineage (identical package IDs and DLL
names: OpenMetaverse.Types.dll). 1.2.13 is what this fork ALWAYS built against and what
the Jolt code was authored against. So the correct fix for a non-member fork maintainer
is: keep OMV on 1.2.13, feed-independent — do NOT chase the unreachable 1.0.6.

5. THE FIX (implemented on jolt/physics-backend)
------------------------------------------------
Vendored OMV 1.2.13 into the fork's existing Library/ HintPath convention and pointed the
centralized reference at it, so every project (Jolt module + its OpenSim chain) resolves OMV
from in-repo DLLs with zero feed and zero cache dependency.

  a) Copied 3 DLLs into Library/ :
        Library/OpenMetaverse.dll
        Library/OpenMetaverse.Types.dll
        Library/OpenMetaverse.StructuredData.dll
     (from the cached 1.2.13 net8.0 assemblies; asmVer 1.2.0.0)

  b) Directory.Build.props: replaced the 3 central OMV <PackageReference> (which upstream
     pinned to 1.0.6 from the NGC feed) with vendored <Reference><HintPath> entries using
     $(MSBuildThisFileDirectory)Library/... + <Private>true</Private>. nini-core (public on
     nuget.org) and Nerdbank.GitVersioning stay as normal PackageReferences.

  c) LegionJolt.csproj: inline OMV/Nini refs already removed during the merge resolution; it
     now inherits the vendored central OMV (still 1.2.13 — goal met).

  Also part of the same merge resolution (from the prior step):
     - Tranquillity.sln conflict resolved as a UNION (kept John's Legion.Physics + LegionJolt
       project entries AND upstream's new OpenSim.Server.Base.Tests).
